speed

▲ BTO — buy‑to‑open (entry)

A buy signal opens a new long option position. Limit order at the signal price + the willing‑to‑pay cap; filled within the pending TTL or it expires.

▼ STC — sell‑to‑close (exit)

A sell signal routes to the live PositionWorkflow, which sells a fraction (or all) of the open lot. Must actually fill — an unfilled exit leaves a live position.

Reconciliation sweeps every 5 min: broker positions vs running PositionWorkflows vs the order journal. Today it is detect‑only — emits PositionOrphan / JournalOrphan and stops. Plan‑2 R1 makes it auto‑adopt; R3 guarantees a bounded force‑flatten before expiry.

Glossary

BTO
Buy‑to‑open — entry; opens a long option position.
STC
Sell‑to‑close — exit; sells a fraction/all of an open lot.
intent journal
Durable per‑order row (RECORDED→SUBMITTED→FILLED/EXPIRED/…) — the exec idempotency ledger.
audit_log
Hash‑chained event ledger in the orchestrator DB; drives Discord alerts.
PositionWorkflow
Long‑lived Temporal workflow that manages one open lot until closed.
OrphanSTC
An STC with no live position to act on.
PositionOrphan
A broker‑held position with no running PositionWorkflow.
